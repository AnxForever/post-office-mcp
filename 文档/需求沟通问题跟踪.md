## 核心业务流确认（已敲定）

> 来源：2026-07-01 沟通

**基本流程**：

```
在线表路线 → 导出表Sheet中匹配对应地点 → 按车牌 + 时间筛选 → 运费对照
```

即：
1. 以**在线表**的路线为基准
2. 去**导出表**的对应 Sheet 中查找匹配的地点（起讫点）
3. 用**车牌号**和**时间**做筛选条件
4. 最终完成**运费的对账/对照**
