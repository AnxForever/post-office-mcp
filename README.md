# 邮局月度委办运输报表 · 项目说明

---

## 一、做什么

每月处理6家物流公司的派车记录 + 两个场地的容积测量 + 价格合同，生成5个Excel交付件。

---

## 二、完整业务流程

```
草滩在线表 + 港务在线表
       ↓ 合并 + 跨场地补容间（串行）
   ①车型汇总表（交付产物，也是容积来源）
       ↓
   车管数据（行来源，4309条派车，6家公司）
       │  自带：邮路/车牌/派车单号/封车时间/运输量
       │
       ├─ 容积/车型问题 → 在线表合并
       │     (日期+车牌)精确 → 同车牌跨站兜底 → 都没有→标橙
       ├─ 吨位 → 容积 vs 价格表档位下限（取最大档）
       ├─ 公里/标准价/系数 → 价格表（标准化路线+吨位）
       └─ 运价 = 系数 × 标准价
              ↓
   ②基础报表初版（21列固定 + 四色标记 + 问题汇总按类型分组）
              ↓ ⛔ 人工核对闸门
   ③拆分版 + ④一干盈亏 + ⑤二干盈亏
```

## 三、容积取数决策

```
车管派车(日期D, 车牌P)
       │
  在线表找(D,P)精确匹配
       │
  有vol>0 ──→ 直接取，不标注
       │
  无/vol=0 ──→ 同车牌在线表任意记录vol>0?
                    │
               找到 → 取该容积，标蓝"串行"
                    │
              没找到 → 标橙"未测量"
```

## 七、匹配键

| 匹配 | 键 |
|---|---|
| 车管 ↔ 在线表(容积) | (日期+车牌)精确 → 同车牌跨站兜底 |
| 车管 ↔ 价格表 | 标准化路线(L0-L6) + 吨位 |
| 财务 ↔ 盈亏 | 路线 + 吨位档 |

## 八、标记与标注

| 标记 | 含义 | 人工动作 |
|---|---|---|
| 红 | 缺失 | 核对数据 |
| 橙 | 完全未测量 | 人工补容间或标缺 |
| 黄 | 跨档 | 确认吨位 |
| 蓝 | 串行跨站点取容积 | 核对容积是否正确 |
| 问题汇总 | 按类型分组+建议动作+处理结果列 | 按类型筛选、批量处理 |
