# 注意事项 / 常见陷阱

## 路径（最容易翻车的一类）

1. AgentOS **没有 `/inputs` 和 `/outputs`**。用户上传在 `/workspace/<文件名>`，输出写 `/workspace/output`。
2. 调脚本前先 `print(os.listdir('/workspace'))` 确认真实文件名，**不要臆造或拼错**（如把「一干委办盈亏」写成「一千季办盈亏」）。
3. 报 `PermissionError: '/outputs/...'` → 输出目录传错了，改成 `/workspace/output`。
4. 报 `FileNotFoundError: '/inputs/...'` → 输入路径传错了，按脚本打印的目录清单改正。
5. 脚本已内置容错：输出目录不可写自动回退到 `./output`；输入不存在会打印清单和相近文件名后 `[STOP]`。**看到 `[STOP]` 必须改正路径重跑，不要原样重试。**

## Windows环境

1. **禁止使用emoji** -- 所有输出用 `[OK]` / `[STOP]` / `[!]` 代替
2. 控制台编码: 运行前必须 `set PYTHONIOENCODING=utf-8` `set PYTHONUTF8=1`
3. Python版本: 不要用Windows Store版python.exe（退出码49），用正式安装版（如Python312）
4. 年份配置: 环境变量 `POST_OFFICE_REPORT_YEAR=2026`（默认2026）
5. **Excel文件打开时无法覆盖** -- 请先关闭再运行

## 草滩在线表

1. Sheet名格式: `M月D日` 或 `M月DD日`（不是 `M.D`）
2. 容积列是公式 `=长×宽×高`，`data_only=True`读取返回None
3. 必须用长宽高硬算: `vol = float(长) * float(宽) * float(高)`
4. 部分Sheet名有尾部空格（如"3月12 "）注意正则匹配

## 港务在线表

1. Sheet名格式: `M.D`（如 `4.1`，不是 `4月1日`）

## 车管数据

1. 文件可能含 `(1)` 后缀（如 `盛丰 (1).xlsx`）-- 脚本会自动清洗
2. 结算吨位在C35列，用于降吨位判断
3. 不同月份公司数量可能不同（3月有运昌华7公司，4/5月6公司）
4. 新增公司时只需更新 `company-map.json`，不用改代码
5. **行来源必须用车管数据**，不是在线表或车型表

## 价格表

1. 第二行是系数（如0.63），第四行才是容积下限（>=55），不要搞混
2. 吨位档名可能含字母（如 `40吨B` `40吨A`）
3. 路线名动态匹配，不写死城市名
4. 一干价格表可能含多个Sheet（单程/往返/草滩）
5. **运价公式: `freight = coeff × price`**，price来自价格表数据，coeff来自吨位档
6. 价格表的price值可能已含系数 → 代码通过`coeff × price`统一处理

## 吨位判定

- 一干: 40吨B(>=180方) / 40吨A(>=150) / 30吨(>=130) / 20吨(>=100) / 12吨(>=55)
- 二干: 40吨(>=130) / 30吨(>=110) / 20吨(>=85) / 12吨(>=55) / 8吨(>=45) / 5吨(>=35) / 2.75吨(>=16)

## 降吨位

1. 车管C35(结算吨位)覆盖车型吨位
2. 仅当**车型吨位>=30吨**且结算档位<车型档位时触发
3. **原运费公式: `原运费 = 当前路线标准价 × 原车型系数`**（不是原车型标准价）
4. 差价 = 当前运费 - 原运费
5. 标深橙色(C65911)，备注写明车型→结算、原运费、差价

## 初版

1. 固定21列，列数只数非空表头，不信 `max_column`
2. 行来源必须用车管数据，不用在线表或车型表
3. 生成后立即停下等人核对，不得直接跑拆版/盈亏
4. 所有不确定必标注，不编造数据
5. 纯数字车型问题 → 标注"含义不明确，请确认"
6. 运价验证: `freight == coeff × price`（脚本内置自检）

## 颜色标注

| 颜色 | 色值 | 类型 | 说明 |
|------|------|------|------|
| 红 | FF6666 | 缺失 | 车管记录完全缺失 |
| 橙 | FFA500 | 未测量 | 在线表当月无任何容积记录 |
| 黄 | FFFF00 | 跨档 | 同车牌不同趟次吨位偏离众数 |
| 蓝 | BBD7EE | 串行 | 容积从同车牌跨站点取得 |
| 深橙 | C65911 | 降吨位 | 结算吨位低于车型吨位 |

## 拆分版

1. 必须等初版人工核对后才能生成
2. **反向路线不放入对应Sheet**（如宝鸡-西安→不入宝鸡Sheet）
3. 模板Sheet排序用短名优先，避免银川→银川往返分裂
4. 容积在拆分版中 `int(round(vol))` 取整
5. **降吨位Sheet**: 自动从初版备注解析原运费/差价，单独生成Sheet
6. 模板中仅含列名无数据的空Sheet不生成

## 盈亏表

1. 模板选择: 优先选含"年"的最新格式Sheet（如26年3月），旧格式（2025版）车型组名不匹配
2. **7列/吨位组**: 趟次 / 装载量 / 平均装载 / 运费 / 结算收入 / 盈亏 / 平均盈亏
3. **4列汇总**: 趟次 / 委办运费 / 结算收入 / 总盈亏，均用SUM公式
4. **环比区**: 上月数据(模板)/本月数据(当前)/环比公式 =(本月-上月)/上月
5. 二干路线自动去掉"西安-"前缀显示
6. 空值写None不留0，数字格式用General
7. 格式: 标题14pt宋体 / 数据10pt / 缩放85% / A列18宽 其余13

## 路线标准化

1. 去掉括号后缀 `(陕2)` `(港1)`
2. 去掉类型后缀 `港/航/旺临/特快/陕串/提速/陕临/车次`
3. 草滩→西安: `西安草滩-` → `西安-`
4. 上海东/西 → 上海
5. 航站- → 去前缀

## 验证规则

1. 运价 = 系数 × 标准价
2. 车型表(路线+车牌)对与官方覆盖率100%
3. 拆分版Sheet行数与官方逐行对齐
4. 盈亏表路线名单与官方对齐
5. 原运费 = 当前标准价 × 原系数
6. 不造数据，空值留空标注颜色
