# 业务流程说明

## 数据流全景

```
草滩在线表 ─┐
            ├─→ ① 车型汇总表 ──→ 容积来源
港务在线表 ─┘

车管数据(6公司) ──→ 行来源(4309行) ─┐
                                     │
一干价格表 ─┐                        ├─→ ② 初版(21列+颜色+问题汇总)
            ├─→ 吨位匹配+价格计算 ──┘
二干价格表 ─┘

核对后初版 ──→ ③ 拆分版(~88 Sheet，按路线×公司)
            ──→ ④ 一干/二干盈亏表
```

## 核心规则

### 行来源
- **必须用车管数据**（6家物流公司派车记录），不是在线表或车型表
- 车管数据字段: 车牌号(C16) 邮路名称(C4) 派车单号(C9) 邮路执行日期(C7) 邮运量(C23) 结算吨位(C35)

### 容积取数
1. 优先: (日期+车牌) 在线表精确匹配
2. 兜底: 同车牌跨站点/跨日期取非零容积（标蓝·串行）
3. 都没有: 标橙·未测量

### 草滩容积特殊处理
- 草滩在线表容积是Excel公式 `=长×宽×高`
- `data_only=True` 读不到 → 必须用 `长×宽×高` 硬算

### 吨位判定
- 一干: 40吨B(>=180方) / 40吨A(>=150) / 30吨(>=130) / 20吨(>=100) / 12吨(>=55)
- 二干: 40吨(>=130) / 30吨(>=110) / 20吨(>=85) / 12吨(>=55) / 8吨(>=45) / 5吨(>=35) / 2.75吨(>=16)
- 价格表吨位档/系数/路线全动态读取，不写死

### 降吨位
- 车管C35(结算吨位) 覆盖 车型吨位
- 仅当**车型吨位>=30吨**时触发
- 结算档位 < 车型档位 → 按结算档位定价
- 标深橙色，备注注明原运费和差价

### 路线标准化
- 去掉括号后缀 `(陕2)` `(港1)`
- 去掉类型后缀 `港/航/旺临/特快/陕串/提速/陕临`
- 草滩→西安: `西安草滩-` → `西安-`
- 上海东/西 → 上海

### 价格匹配
- L0-L6 逐级标准化匹配
- 一干/二干判定: 二干目的地从二干价格表动态派生
- 匹配不到标红

## 问题分类和颜色

| 颜色 | 类型 | 说明 |
|------|------|------|
| 红 | 缺失 | 车管数据缺失（理论为0） |
| 橙 | 未测量 | 在线表当月无任何记录 |
| 黄 | 跨档 | 同车牌不同趟次吨位不同 |
| 蓝 | 串行 | 容积从同车牌跨站点取得 |
| 深橙 | 降吨位 | 结算吨位低于车型吨位 |

## 拆分版规则

1. 按路线目的地+公司拆分到对应Sheet
2. 排除反向路线（如 宝鸡-西安 不放入宝鸡Sheet）
3. 同一个目的地存在多个Sheet时(如银川/银川往返)，优先基础Sheet
4. 容积在拆分版中取整显示

## 盈亏表规则

1. 装载量/运费 来自初版「基础报表」sheet（按 路线+吨位 聚合）
2. 趟次/结算收入 来自财务收入表（结算收入 = Col23 - Col31 普服收入）
3. 盈亏 = 结算收入 - 运费
4. 格式照搬盈亏模板（列数/表头/路线顺序）
5. 目标月份匹配对应模板Sheet（如4月匹配"4月"或"26年4月"Sheet）
