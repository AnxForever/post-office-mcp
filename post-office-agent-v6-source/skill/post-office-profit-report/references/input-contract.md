# 盈亏表输入契约

只用两份文件，缺一不可。价格表、盈亏模板、车管派车数据、在线测量表都不需要。

## 1. 基础报表原版

必须同时含这两个工作表：

### 一干汇总 / 二干基础

| 用途 | 表头（别名任一） | 是否必需 |
|---|---|---|
| 邮路 | 邮路名称 | 必需 |
| 容间分档 | 容间 | 必需 |
| 装载量 | 运输量 / 邮运量 | 必需 |
| 运费 | 运价 | 必需 |
| 收入配对 | 车牌号 | 必需 |
| 日期 | 封车时间 / 邮路执行日期 / 邮路执行时间 | 必需 |
| 备注 | 备注 | 可选 |

- 按表头别名匹配，不要求列顺序。
- 「吨位」列可以没有；有也不参与分组。2026-09 客户给的一干汇总就没有吨位列（18 列，改成系数/基准运价）。
- 首列「序号」必须是整数，用来跳过表头重排、合计行、空行。
- 「两趟合一趟」「降吨位」等特殊 sheet 的记录已经包含在上面两个 sheet 里，不重复统计。

## 2. 财务收入表

第一个工作表，表头必须包含：

| 列 | 用途 |
|---|---|
| 邮路级别 | 判定一干/二干（含「一干」→ 一干，否则二干） |
| 自委办 | 只取「委办」行 |
| 结算收入 | 收入主项 |
| 普服收入 | 从结算收入里扣掉 |
| 邮路名称 | 路线（用于改判和反向路线归并） |
| 车牌号 / 流水号 | 逐趟配对（流水号前 4 位是 MMDD 日期） |

- 反向路线（`银川-西安`、`榆林-西安` 等以 `-西安` 结尾）不参与逐趟配对，按官方口径并入对应的正向路线。
- 财务表的「额定吨位」「实载重量」一律不读。

## 容间分档（客户 2026-10 书面确认）

| 容间（m³） | 表头档位 |
|---|---|
| < 55 | 小于55 |
| [55, 100) | [55,100) |
| [100, 130) | [100,130) |
| [130, 150) | [130,150) |
| [150, 180) | [150,180) |
| ≥ 180 | 大于180 |

180 整归「大于180」。

## 停下来的条件

| status | 触发条件 |
|---|---|
| `missing_base_sheet` | 缺「一干汇总」或「二干基础」 |
| `unreadable_base` | 必需列缺失 |
| `empty_base` | 两个 sheet 一行有效数据都没读到 |
| `month_mismatch` | 业务日期比目标月旧（文件没更新） |
| `finance_mismatch` | 超过一半派车记录配不上收入，两份文件很可能不同月 |
| `needs_input` | 两份文件没找齐或识别不唯一 |
| `needs_month` | 推断不出月份 |
