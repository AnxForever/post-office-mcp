# 盈亏表输入契约

只用两份文件，缺一不可。价格表、盈亏模板、车管派车数据、在线测量表都不需要。

## 1. 基础报表原版

必须同时含这两个工作表：

### 一干汇总 / 二干基础

| 用途 | 表头（别名任一） | 是否必需 |
|---|---|---|
| 邮路 | 邮路名称 | 必需 |
| 档位 | 吨位 或 容间（有吨位用吨位，没有才用容间） | 二者至少一个 |
| 装载量 | 运输量 / 邮运量 | 必需 |
| 运费 | 运价 | 必需 |
| 收入配对 | 车牌号 | 必需 |
| 日期 | 封车时间 / 邮路执行日期 / 邮路执行时间 | 必需 |
| 备注 | 备注 | 可选，但吨位口径下很重要 |

- 按表头别名匹配，不要求列顺序。
- **不按一干/二干写死分档依据**：哪张表带了「吨位」列且有值，就按吨位分；
  没有吨位列（或整列为空）才按容间分。2026-09 的一干汇总没有吨位列、二干基础有；
  哪天反过来，脚本也会跟着数据走。
- 首列「序号」必须是整数，用来跳过表头重排、合计行、空行。
- 「两趟合一趟」「降吨位」等特殊 sheet 的记录已经包含在上面两个 sheet 里，不重复统计。

## 2. 财务收入表

第一个工作表，表头必须包含：

| 列 | 用途 |
|---|---|
| 邮路级别 | 判定一干/二干（含「一干」→ 一干，否则二干） |
| 自委办 | 只取「委办」行 |
| 结算收入 | 收入主项 |
| 普服收入 | 从结算收入里扣掉 |
| 邮路名称 | 路线（用于改判和反向路线归并） |
| 车牌号 / 流水号 | 逐趟配对（流水号前 4 位是 MMDD 日期） |

- 反向路线（`银川-西安`、`榆林-西安` 等以 `-西安` 结尾）不参与逐趟配对，按官方口径并入对应的正向路线。
- 财务表的「额定吨位」「实载重量」一律不读。

## 分档规则

| 表里有什么 | 怎么分 |
|---|---|
| 有「吨位」列且有值 | 按吨位分车型 |
| 没有「吨位」列，或整列为空 | 按容间区间（下表） |
| 个别行没吨位、但有容间 | 按容间推回吨位档：≥16→3、≥35→5、≥45→8、≥55→12、≥100→20、≥130→30、≥150→40A、≥180→40B |

### 吨位口径

「吨位」列就是车型档（3 / 12 / 20 / 30 / 40A / 40B …），40 与 40A 在二干模板里合并显示为
「40（40A）」。备注写「两辆12吨的车合并一辆30吨的车」「调度通知按30吨结算」
「合并一辆40A的车」的，整行按备注的吨位算；没写备注的，按该车该路线跑过的最低档算。

客户确认过的单趟结算吨位（按「邮路关键字 + 车牌 + 日期」登记在脚本顶部
`_CONFIRMED_SETTLEMENTS`）优先于容间推算，只对确认过的那一趟生效；备注里有明确写法的
仍以备注为准。修正过的趟次会写在问题清单里。一干/二干归属仍按财务收入表的「邮路级别」走。

### 容间口径（没有吨位列时）

| 容间（m³） | 表头档位 |
|---|---|
| < 55 | 小于55 |
| [55, 100) | [55,100) |
| [100, 130) | [100,130) |
| [130, 150) | [130,150) |
| [150, 180) | [150,180) |
| ≥ 180 | 大于180 |

180 整归「大于180」。脚本会在问题清单里写明本月每张表实际用了哪种口径。

## 收入没对上的怎么处理

- 基础报表有趟次、财务收入表里没找到收入：**不进结果表**，逐趟列进问题清单。
- 财务收入表里有收入、基础报表里找不到对应派车：**不进结果表**，逐笔列进问题清单。
- 车牌在基础表里、但日期/趟次没对上：**不进结果表**，逐笔列进问题清单。

不让 0 元或估算值影响主表的运费、收入和盈亏。出表后脚本会逐行复核
「路线行相加 = 合计行 = 基础汇总」；对不上返回 `reconciliation_failed`，不交付。

## 停下来的条件

| status | 触发条件 |
|---|---|
| `missing_base_sheet` | 缺「一干汇总」或「二干基础」 |
| `unreadable_base` | 必需列缺失 |
| `empty_base` | 两个 sheet 一行有效数据都没读到 |
| `month_mismatch` | 业务日期比目标月旧（文件没更新） |
| `finance_mismatch` | 超过一半派车记录配不上收入，两份文件很可能不同月 |
| `needs_input` | 两份文件没找齐或识别不唯一 |
| `needs_month` | 推断不出月份 |
