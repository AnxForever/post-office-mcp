# 输入契约

## 模式 A：仅车型汇总

必须提供目标月 `YYYY-MM` 以及两个工作簿：

- 草滩在线测量表1个，日 Sheet 名如 `4月1日`。
- 港务在线测量表1个，日 Sheet 名如 `4.1`。

在线表必须可发现邮路、车牌、挂车和容积字段。草滩容积公式没有缓存值时，必须可发现长、宽、高。

## 模式 B：完整月度流程

当 `company-map.json` 保持默认6家公司时，阶段一需要14个动态工作簿：

| 角色 | 数量 | 必需结构 |
|---|---:|---|
| 草滩在线测量表 | 1 | 目标月日 Sheet；邮路、车牌、挂车、容积 |
| 港务在线测量表 | 1 | 目标月日 Sheet；邮路、车牌、挂车、容积 |
| 车管基础数据 | 按公司映射 | 邮路名称、邮路执行日期、派车单号、车牌号、车厢码/挂车号、邮运量、结算吨位 |
| 财务收入表 | 1 | 邮路名称、额定/结算吨位、结算收入、普服收入 |
| 一干价格表 | 1 | 路线、公里、吨位、容积下限、系数、标准价 |
| 二干价格表 | 1 | 同上 |
| 基础报表初版模板 | 1 | 完整21列业务表头，表头位置可变 |
| 一干委办盈亏模板 | 1 | 月份页、7列吨位分组、路线和合计行 |
| 二干委办盈亏模板 | 1 | 同上 |

车管文件数量等于 `company-map.json` 中的公司数，每家正好1个。新增公司时先增加公司映射，不修改业务代码。

文件名只作辅助信号，以工作表结构和字段为准。输入损坏、角色冲突、必需字段缺失、公司映射缺失或目标月份不一致必须阻断。

## 阶段二输入

- 必须保留阶段一生成的 `output/run-state.json`。
- 必须上传人工核对后的 `{M}月_02_基础报表初版.xlsx`。
- 可选上传上月一干和二干盈亏表，用于生成环比。

人工可修正容间、价格等核对字段，但不得改变行数、行顺序及车管权威字段（承运单位、派车单号、邮路、执行日期、车牌和挂车）。修订容间后，脚本重算吨位、系数、标准价、运价和跨档。

## Skill 静态资产

- `assets/split-report-template.xlsx`：拆分版母版。
- `assets/company-map.json`：车管文件名公司代号到全称的映射。
- `assets/route-aliases.json`：显式路线别名及一干/二干归属。

阶段一将所有动态源文件、模板布局和静态资产的 SHA-256 写入运行状态。阶段二任一锁定文件缺失或变更时必须阻断。
