# 邮局基础报表拆分

只运行本技能里的 `agentos_entrypoint.py`，不要自己写临时脚本、不要自己读写 Excel。

## 输入

只要一份文件：

- **人工核对后的 02 基础报表初版**，必须同时含「基础报表」和「拆分元数据」两个 Sheet

价格表默认用技能内置合同表，只用于路线归属分类，**不会覆盖 02 里人工核对过的吨位和运费**。
如果当月合同价目有变化，可显式传 `--first-price` / `--second-price`。

## 一条命令做完

```python
import runpy, sys
sys.path.insert(0, "{skill_dir}/scripts")
sys.argv = ["agentos_entrypoint.py", "--workspace", "/workspace"]
runpy.run_path("{skill_dir}/scripts/agentos_entrypoint.py", run_name="__main__")
```

- 不传 `--month`：从 02 的封车时间推断；推断不出返回 `needs_month`。
- 返回 `status:"split_completed"` 就是做完了，汇报 `metrics.unmatched` 和页签数量。
- 返回 `needs_input`：上传目录里没有 02，或同时有多份 02，把 `missing_inputs[].action`
  转告用户。

## 反复修正怎么重跑

用户在 02 上改完再拆，常常不止一轮。重跑时按下面处理：

| 情况 | 做法 |
|---|---|
| 输出目录已有 03 | 默认返回 `output_exists`，**不要自动覆盖**；先问用户 |
| 用户确认旧 03 不要了 | 带 `--force` 重跑 |
| 用户只是在 02 里插行、删行、改吨位/运费/备注 | 直接重跑即可；元数据按车牌+日期+派车单号+邮路匹配，行号漂移不影响 |
| 只是想保留旧 03 | 换一个新的 `--output-dir`，不要加 `--force` |

拆分只读 02，不写回 02；所以用户改完 02 后随时可以重跑，03 永远以最新 02 为准。

## 输出

`N月_03_基础报表拆分版.xlsx`：

- 约 100 个路线页签，每页按 02 的「标准邮路」分组，含合计行
- 特殊页签：`一干汇总`、`二干基础`、`两趟合一趟`、`降吨位`
- `※未匹配目的地`：路线名对不上模板页签的记录，全部保留在这里，不丢行

**硬校验**：各页签记录数之和必须等于 02 行数，否则不出表。

## 口径

- 02 是人工核对后的权威数据；拆分阶段只重算「路线归属」，不改吨位、运费、备注。
- 路线被人工改过的行（元数据里的邮路名称和 02 不一致）才按价格表重新分类。
- 「※未匹配目的地」不是失败，是留给人工检查的清单，不要为了消掉它去改路线名。

## 停下来的情况

| status | 含义 | 怎么跟用户说 |
|---|---|---|
| `needs_month` | 推断不出月份 | 问“这是哪一年的哪个月？” |
| `needs_input` | 没有 02 或多份 02 | 逐条转述 `missing_inputs[].action` |
| `output_exists` | 输出目录已有 03 | 先问用户；确认覆盖带 `--force`，否则换输出目录 |
| `split_completed` | 03 已生成 | 汇报记录数和未匹配条数，可继续跑盈亏 |
| `ok:false` | 02 缺拆分元数据、行数对不上 | 原样转述 `errors`，让用户检查 02 |
