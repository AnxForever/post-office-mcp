# 邮局基础报表初版

只运行本技能里的 `agentos_entrypoint.py`，不要自己写临时脚本、不要自己读写 Excel。

## 输入

| 角色 | 数量 | 说明 |
|---|---|---|
| 车型汇总表（01） | 1 | 上一阶段交付件，必须含「车型汇总」Sheet |
| 车管数据 | 6 家 或 1 份平台汇总 | 行来源必须用车管派车记录，不用在线表 |
| 一干价格表 | 1 | 没上传时用技能内置合同表 |
| 二干价格表 | 1 | 没上传时用技能内置合同表 |
| 初版模板 | 0-1 | 不上传时用技能内置模板 |
| 基础报表原版 | 0-1 | 可选；上传后逐单对价，只用于标问题，不参与计价 |

按表结构识别，不看文件名。缺关键文件或同一角色多份时返回 `needs_input`，
把 `missing_inputs[].action` 逐条告诉用户，不要自己挑文件。

## 一条命令做完

```python
import runpy, sys
sys.path.insert(0, "{skill_dir}/scripts")
sys.argv = ["agentos_entrypoint.py", "--workspace", "/workspace"]
runpy.run_path("{skill_dir}/scripts/agentos_entrypoint.py", run_name="__main__")
```

- 不传 `--month`：从 01 的测量日期推断；推断不出返回 `needs_month`。
- 返回 `status:"draft_completed"`：**立刻停下**，把输出文件和 `metrics` 汇报给用户，
  等人工打开 02 核对颜色行和「问题汇总」。不要自动继续拆分。
- 返回 `needs_input` / `needs_month`：不是报错，把缺什么、问什么转告用户。

## 反复修正怎么重跑

用户会来回改数据、重新上传文件，02 不是一次成型的。重跑时按下面处理：

| 情况 | 做法 |
|---|---|
| 输出目录已有 02 | 默认返回 `output_exists`，**不要自动覆盖**；先问用户 |
| 用户确认旧版不要了 | 带 `--force` 重跑 |
| 旧版有人工核对结果要保留 | 带 `--previous-review <旧02>`；技能会把上一版改过的容间、吨位、运费、标准价、备注等按车牌+日期+派车单号+邮路带回，`metrics.previous_review_merged` 是带回来的行数 |
| 只是想保留旧版 | 换一个新的 `--output-dir`，不要加 `--force` |

`--previous-review` 会以旧 02 的值为准覆盖本次自动计算结果，所以只在用户确实核对过旧版时使用；
如果用户改的是车管源数据、希望全部重算，就不要带这个参数。

## 输出

`N月_02_基础报表初版.xlsx`：

- Sheet「基础报表」：固定 21 列（序号…系数），行数=车管派车行数
- Sheet「问题总结」：客户先看的汇总页，按问题类型列出严重程度、涉及行数、问题说明、
  建议处理和主要涉及邮路；打开 02 默认停在这一页
- Sheet「问题汇总」：逐行明细，每条问题带行号、车牌、邮路、问题详情、建议动作、处理结果
- Sheet「结构发现」：输入文件和价格表识别情况
- Sheet「拆分元数据」：每行对应的来源 ID、干线归属、标准邮路、车型/结算吨位等，
  供下一阶段拆分技能独立读取。**人工修订 02 时不要删除或打乱这个 Sheet。**

## 口径

- 行来源必须用车管派车记录；在线测量表只提供容间，不单独成行（在线独有行会标出来）。
- 容间取数：日期+车牌精确 → 同车牌跨站兜底 → 都没有标橙。
- 草滩容积是公式列，`data_only` 读不到时按长×宽×高重算。
- 价格表吨位档、系数、路线全部动态读取，不写死。
- 陇南 2026-09-08 苏E6W073（容间 35、运费 2250）按 3 吨结算，只在盈亏阶段生效。
- 固原/天水/平凉/庆阳/陇南属于二干，是每月固定规则。
- 所有不确定的都必须写进「问题汇总」并在单元格标色，不能静默略过。

## 停下来的情况

| status | 含义 | 怎么跟用户说 |
|---|---|---|
| `needs_month` | 推断不出月份 | 问“这是哪一年的哪个月？” |
| `needs_input` | 缺 01/车管/价格表 | 逐条转述 `missing_inputs[].action` |
| `output_exists` | 输出目录已有 02 | 先问用户是否覆盖；要覆盖带 `--force`，要保留人工修改带 `--previous-review` |
| `draft_completed` | 02 已生成 | 让用户打开核对；**不要自动跑拆分** |
| `ok:false` | 文件读不了、月份不合法 | 原样转述 `errors` |
