# 吨位档位规则 — 读取方法

> 以下数值是 2024-2026 年合同中的实际值，仅供参考。
> **每次核对时必须从实际价格表中重新读取**，因为合同更新后数值会变化。

## 如何从价格表读取档位

价格表的结构（以实际表为准，以下为常见布局）：

```
Row 1: 标题（如"2024年10月一干新招标合同运价"）
Row 2: 序号 | 物流公司 | 路向 | 路向里程 | 系数0.63 | 系数0.83 | 系数1 | ...
Row 3:       |         |      |          | 12吨（9.6米）| 20吨（13.5米）| 30吨（15米）| ...
Row 4:       |         |      |          | (≥55立方米）| (≥100立方米）| (≥130立方米）| ...
Row 5+: 数据行（路线 + 各吨位的价格）
```

**解析步骤：**
1. 找到包含吨位信息的行（含"吨"和"米"的那行）→ 这是吨位名称
2. 下一行通常含容积条件（含"方"或"立方米"或"m³"）→ 提取数值作为容积下限
3. 吨位列对应的系数（或价格）用于后续计算

**注意：**
- 一干价格表可能分多个 Sheet（单程、往返、草滩）
- 二干价格表通常分单程和往返
- 列数可能不同（有的合同多几个吨位档）
- 系数列的位置以表头为准，不要假设它在第几列

## 路线类型判定

二干路线名单 = 从二干价格表的"路向"列提取所有路线名。
基准表中的路线若能在二干路线名单中匹配到 → 二干，否则 → 一干。
匹配时支持部分匹配（路线名可能有括号后缀如"西安-安康(陕T1)"，但"西安-安康"在二干表中）。
