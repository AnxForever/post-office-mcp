# 字段规则字典（每个字段：从哪查 · 怎么匹配 · 怎么算）

> 核心原则：**任何字段位置、Sheet 名、吨位档、系数都不写死——运行时从实际文件表头动态发现。**
> 价格表会加档/改价、邮路会改名、基准表某月有标题行某月没有、草滩和港务列名不一样。
> 所以脚本先"发现结构"再"取数"，并把发现结果写进初版的「结构发现」Sheet 供人工核验。
>
> 目录：① 通用发现方法 ② 在线表 ③ 基准表 ④ 价格表 ⑤ 车管 ⑥ 财务表 ⑦ 盈亏模板 ⑧ 21列逐字段 ⑨ 已观测到的结构差异

---

## ① 通用发现方法（三个脚本共用）

- **找表头行** `find_header_row(ws, keywords)`：扫前 8 行，命中关键词最多的行即表头行。数据从"表头行+1"起。
- **按表头定位列** `locate_ordered(ws, hrow, [(字段,[关键词按优先级])])`：按顺序解析，**已占用的列不复用**。
  必须先解析更具体的字段——例：`车厢车牌号`(挂车) 要在 `车牌号`(车牌) 之前定位，否则 `车牌号` 会误命中 `车厢车牌号`。
- **绝不用固定列号**。列号会因源文件改版而变。

## ② 在线容积测量表（草滩 / 港务）

- **文件**：草滩表、港务表（各一份，含全年按日 Sheet）。
- **Sheet 定位**：按月份匹配 Sheet 名。草滩格式 `M月D日`（正则 `^(\d+)月(\d+)日?$`），港务格式 `M.D`（`^(\d+)\.(\d+)$`）。
  不认识的格式就扫所有 Sheet 名、提数字比月份。
- **表头行**：含"序号/邮路/车"的行（草滩港务都在第 3 行，但**不要写死**，动态找）。
- **列定位（关键词，覆盖两场地不同叫法）**：
  | 字段 | 关键词（优先级） |
  |---|---|
  | 挂车 | 车厢车牌号 / 车厢码 / 挂车号 / 挂车 |
  | 车牌 | 车牌号 / 车号 |
  | 邮路 | 邮路名称 / 邮路 / 路线 |
  | 长/宽/高 | 长 / 宽 / 高 |
  | 容间 | 测量容积 / 容积 |
  | 车型问题 | 车型问题 / 问题 |
- **取数**：表头行下逐行读，邮路和车牌都空则跳过。**严禁去重**。加"来源"标记场地。

## ③ 车型基准表（当月跑了哪些车的清单，报表的行来源）

- **文件**：`N月车型.xlsx` / `N月车型汇总.xlsx`，用 `Sheet1`（不存在则第一个 Sheet）。
- **表头行**：含"序号/邮路/车牌/车号"最多的行——**逐月不同**（见 ⑨）。数据从表头行+1 起。
- **列定位**：挂车(车厢车牌号/车厢码/挂车号)、车牌(车牌号/车号)、邮路(邮路名称/邮路)、容间(测量容积/容积)、车型问题。
- **匹配键**：`(车牌号, 挂车号)`，都转大写。挂车 `--`/空 = 无挂车，合法。

## ④ 价格表（一干 / 二干）——吨位档与系数全部动态解析

价格表决定运价，是最关键的来源。**吨位档、系数、容积下限、价格列位置都从表头动态解析**：

- **价格 Sheet 识别**：遍历文件所有 Sheet，凡能解析出吨位档且有路线数据的即价格 Sheet
  （一干有 单程/往返/草滩 三张，二干一张；空 Sheet 自动跳过）。**保留 Sheet 顺序，路线首次出现为准**（单程优先于往返）。
- **三行表头动态识别**（不写死行号）：
  | 行 | 识别法 | 例（一干 / 二干） |
  |---|---|---|
  | 吨位行 | 含≥2 个"X吨"的行 | `12吨（9.6米）` / `2.75吨` |
  | 系数行 | 含"系数"字样的行 | `系数0.63` / 数值 `0.45`（标签列写"系数"） |
  | 容积下限行 | 含"≥"或"m3/立方米"的行 | `(≥55立方米）` / `4.2米(≥16m3)` |
- **价格列 = 吨位行有吨位名 且 系数行能解析出系数**。这条规则自动排除二干的"返程"列（返程列系数行是"返程"两字，解析不出数字）。
- **解析函数**：
  - 吨位名：正则 `(\d+\.?\d*吨[A-B]?)`（支持 `2.75吨`、`40吨A`）。
  - 系数 `parse_coef`：数字直接用；`系数0.63`/`系数 1` 抽数字；无数字→None（该列不是价格列）。
  - 容积下限 `parse_limit`：从 `≥55` / `(≥16m3)` 抽数字。
- **路线/公里列**：在表头区找——路线(路向/邮路/路线)、公里(里程/公里/KM)。
- 得到每档 `(容积下限, 吨位名, 系数, 列号)`，按下限降序。

## ⑤ 车管基础数据（各物流公司派车记录）

- **文件**：车管目录下各公司 `.xlsx`（文件名=公司简称，脚本自动清洗 `盛丰 (1).xlsx` 的 ` (1)` 后缀）。
- **表头行**：含"车牌号/派车单号/邮运量"的行（当前在第 1 行，动态找）。
- **列定位**：车牌(车牌号/车号)、车厢(车厢码/车厢车牌号/挂车)、派车单号、封车(邮路执行日期/封车)、运输量(邮运量/运输量)。
- **匹配键**：`(车牌号, 车厢码)` 转大写。派车单号去 `.0` 后缀。
- **公司全称**：简称→全称映射是**外部知识**（全称不在源文件里），见 `../company-map.json`，
  新增公司/改简称须确认后更新。某月缺某公司文件（如 5 月无运昌华）→相关记录车管留空，属正常，自检会如实反映。

## ⑥ 财务收入表（盈亏用）

- **表头行 1**，列全部按名定位（**不写死 Col9/19/23/31**）：
  | 字段 | 关键词 | 用途 |
  |---|---|---|
  | 邮路级别 | 邮路级别 | 判一干/二干（含"一干"即一干） |
  | 邮路名称 | 邮路名称 | 路线（标准化后作聚合键） |
  | 额定吨位 | 额定吨位 | 映射吨位档（=0/空则跳过） |
  | 结算收入 | 结算收入 | 结算收入 |
  | 普服收入 | 普服收入 | 结算收入需减去它 |
- **口径**：一干跳过不以"西安"开头的反向路线；一/二干路线键最终服从最近有效盈亏模板，模板用全路线就匹配全路线，模板用目的地就匹配目的地。

## ⑦ 盈亏模板（一干委办盈亏 / 二干委办盈亏）

- **模板 Sheet**：筛选月份名且 Row2 Col1 为“邮路名称”的 Sheet，取最后一个有效月份；禁止直接取第一张。
- **车型组(列)**：Row2 里非"邮路名称/趟次/委办运费/结算收入/总盈亏"的合并单元格即车型组；每组 7 个子列。
- **组吨位键**：从组名正则 `(\d+\.?\d*吨[A-B]?)`（支持 `2.75吨`）；`40A/40B` 无"吨"字的写法特判为 `40吨A/40吨B`。
- **路线顺序**：col1 第 4 行到“合计”前，原样照搬。不同月份二干可能是城市名，也可能是`西安-城市`全名。
- **环比区**：从最近模板的“合计”后定位`上月/本月/环比`结构；新输出以上月实际值、本月汇总值和公式更新。

运费=初版 sum(运价)；盈亏=结算收入−运费。财务额定吨位→吨位档按最近有效模板的车型组动态映射；
同数值 A/B 档中 A 作为该数值上限，最后一档 B 作为更大吨位兜底。无法解析时必须停止并标注。

## ⑨ 已观测到的结构差异（正因如此才要动态发现）

- **基准表逐月不同**：3/4 月有标题行+日期行、表头在**第 3 行**、列名用"邮路/车号/挂车号"；
  5 月无标题、表头在**第 1 行**、列名用"邮路名称/车牌号/车厢车牌号"。写死"第 4 行起"会漏掉 5 月前 2 条数据。
- **草滩 vs 港务列名不同**：草滩"车号/挂车号/邮路"，港务"车牌号/车厢车牌号/邮路名称"。关键词表须同时覆盖。
- **二干价格表有"返程"列**：Row3 又写一个"12吨"，但 Row2 是"返程"无系数——按"价格列需有系数"规则自动排除。
- **一干价格表混入空 Sheet**（Sheet1/2/4）：有档位表头但无路线数据——按"须有路线行"过滤掉。
- 结论：**每次运行都重新发现**，把结果写进初版「结构发现」Sheet；发现结果与预期不符即源文件改版，先核对再取数。
