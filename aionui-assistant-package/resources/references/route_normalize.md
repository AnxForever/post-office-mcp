# 路线名标准化 L0-L6

三个子 skill 内置**同一套** `std(rt, to_dest=False)`。分层清洗，逐层去噪，用于把在线表/基准表/
财务表里五花八门的路线名，规整到能和价格表/盈亏模板对上的标准形。

## 分层规则（在 draft 匹配价格时，从 L0 逐层尝试，匹配到就停）

| 层 | 处理 | 正则/操作 |
|:--:|---|---|
| L0 | 原始路线名 | 不动 |
| L1 | 去括号内容 | `re.sub(r'\([^)]*\)', '', r)` |
| L2 | 去业务后缀+数字 | `re.sub(r'(港\|航\|旺临\|特快\|港航\|港T串?\|陕T?\|陕串?\|车次\|港串?\|提速\|陕临)\d*$', '', r)` |
| L3 | 去"转""本" | `re.sub(r'(转\|本)$', '', r)` |
| L4 | 去"废"+数字 | `re.sub(r'废\d+$', '', r)` |
| L5 | 航站→普通 | `航站-` → `-` |
| L6 | 场地/别名归一 | `西安草滩-`→`西安-`；`-上海东/-上海西`→`-上海` |

`to_dest=True` 时：结果若以 `西安-` 开头，去掉 `西安-` 前缀，只留目的地城市（二干用）。

## 两干线的路线键约定（务必一致，否则财务↔初版↔模板对不上）
- **一干**：全名 `西安-城市`（如 `西安-杭州`）。财务侧过滤掉不以"西安"开头的反向路线。
- **二干**：只取目的地城市名（如 `安康`）。

## ⚠️ 一/二干分类：动态派生，不写死城市名
- **draft**：从二干价格表 col2 派生二干目的地集合 `ergan_dests`，`is_er(route)=std(route,to_dest=True) in ergan_dests`。
- **pnl**：从二干盈亏模板 col1 派生二干城市集 `er_cities`（剔除"省内短线"/"合计"）。
- **为什么**：早期写死 `SHORT_CITIES` 城市列表，把 `固原/平凉/陇南/庆阳/天水` 误判为二干（它们实为一干、
  只在一干价格表有价），导致分错表→丢标准价、并在问题汇总里产生大量假"价格表未覆盖"误报。改为动态派生后，
  分类口径永远跟随实际价格表/模板，3/4/5 月标准价匹配率显著回升、问题条数大降。

## 盈亏模板路线名 = 权威清单
- 一干盈亏模板 col1：`西安-城市` 全名。
- 二干盈亏模板 col1：城市名（还有 `省内短线` 这种聚合桶）。
- pnl 只对模板 col1 列出的路线落数；不在模板里的路线**不进盈亏表**（这是设计，不是漏算）。

## Python 参考实现
```python
def std(rt, to_dest=False):
    r = rt.strip(); r = re.sub(r'\([^)]*\)', '', r).strip()
    r = re.sub(r'(港|航|旺临|特快|港航|港T串?|陕T?|陕串?|车次|港串?|提速|陕临)\d*$', '', r).strip()
    r = re.sub(r'(转|本)$', '', r).strip(); r = re.sub(r'废\d+$', '', r).strip()
    r = r.replace('航站-', '-').replace('西安草滩-', '西安-')
    r = r.replace('-上海东','-上海').replace('-上海西','-上海')
    if to_dest and r.startswith('西安-'): r = r[3:]
    return r
```
