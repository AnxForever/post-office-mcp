# 决策树：报表生成常见歧义处理

## 容积取不到时

```
在线表当月有记录？
  ├─ 是 → (日期+车牌)精确匹配 → 取非零容积
  │        └─ 该记录容积=0？
  │             ├─ 是 → 同车牌跨站点找 → 标蓝"串行"
  │             └─ 否 → 直接用
  └─ 否 → 同车牌跨站点/跨日期找
           ├─ 找到 → 标蓝"串行"
           └─ 没找到 → 标橙"未测量"
```

## 路线匹配不上价格表

```
L0: 原始路线名 → L1: 去括号后缀 → L2: 去类型后缀
→ ... → L6: 上海东/西→上海
  ├─ 命中 → 用
  └─ 未命中 → 标红"价格表未覆盖"
```

## 降吨位判定

```
结算吨位(C35) 有值？
  ├─ 否 → 不触发
  └─ 是 → 车型吨位 >= 30吨？
           ├─ 否 → 不触发
           └─ 是 → 结算档位 < 车型档位？
                    ├─ 否 → 不触发
                    └─ 是 → 触发，标深橙
```

## 生成完初版下一步

```
初版已生成
  ├─ 用户请求做拆分版/盈亏表？
  │   ├─ 是 → 问"初版核对过了吗？"
  │   └─ 否 → 主动提示"初版需要人工核对"
  └─ 默认 → 交付初版，立即停止
```
