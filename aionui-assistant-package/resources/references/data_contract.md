# 数据契约：初版「基础报表」sheet（v1.16，21 列）

这是三个子 skill 之间**唯一的数据契约**。`draft` 产出它；`split` 和 `pnl` 读它。
拆分/盈亏读的是**人工核对修正后**的这张表，所以人工的修正会自然生效。

## 21 列定义（列序不可变）

| 列 | 列名 | 含义 | 来源 |
|:--:|---|---|---|
| 1 | 序号 | 行号 | 生成 |
| 2 | 车辆承运单位 | 公司全称 | 车管(简称→全称映射) |
| 3 | 派车单号 | | 车管(去 `.0` 后缀) |
| 4 | 邮路名称 | 路线原始名 | 车型基准表 |
| 5 | 路单编号 | | 预留 |
| 6 | 封车时间 | 邮路执行日期 | 车管 |
| 7 | (空列) | | — |
| 8 | 车牌号 | | 车型基准表 |
| 9 | (空列) | | — |
| 10 | 容间 | 容积(方)，**保留原始精度** | 在线表/补量 |
| 11 | 吨位 | 12吨/20吨/…/2.75吨 | 容间对吨位档 |
| 12 | 公里 | | 价格表 |
| 13 | 运输量 | 装载量(袋件) | 车管 邮运量 |
| 14 | 路单号 | | 预留 |
| 15 | 运价 | **=系数×标准价** | 计算 |
| 16 | 标准价 | 价格表对应吨位列**直取** | 价格表 |
| 17 | 备注 | 原始车型问题 + 【⚠️需核对】问题详情 | 生成 |
| 18 | 是否跨档 | 是/否 | 跨档判定 |
| 19 | 变动前容间 | 同车牌上一条的容间 | 生成 |
| 20 | 变动前时间 | 同车牌上一条的日期 | 生成 |
| 21 | 系数 | 吨位档系数(如 0.63) | 吨位档 |

## 行底色标记
- 🔴 红(FF6666)：缺失——合并在线表完全找不到该车牌
- 🟠 橙(FFA500)：未测量——在线表有车牌但容间=0 且长宽高全空
- 🟡 黄(FFFF00)：跨档——同车牌该次吨位偏离其最常见吨位

## split / pnl 读取时用到的列
- **split**：2,3,4,6,8,10,11,12,13,15,16,17
- **pnl (basic_sum)**：4(路线)、11(吨位)、13(运输量)、15(运价)

读取时若 `基础报表` sheet 不存在，退回最后一个 sheet；空行(路线和车牌都空)跳过。
