# 模型与运行环境要求

## 模型能力

建议使用支持长上下文、工具调用和代码执行的中高端模型。最低能力要求：

- 能读取多份 SKILL/参考文档并保持阶段边界；
- 能调用 Python 脚本并根据 stdout 决定下一步；
- 能在 Excel 结构变化时写小型探查代码；
- 能区分“事实、推断、待确认”，不把猜测写入金额字段；
- 能遵守初版后的人工闸门。

模型能力不能替代验证。所有模型都必须运行结构探查、输出验证和回归测试。

## 环境能力

- Python 3.10+
- `openpyxl`
- 可读写用户提供的 Excel 与输出目录
- 可执行 `inspect_sources.py`、`verify_draft.py`、`test_runner.py`

## 降级策略

若模型不能执行代码或无法访问文件：只做文件清单与规则说明，不得声称已生成或已验证报表。
