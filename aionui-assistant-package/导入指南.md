# 邮局委办报表助手 · AionUi 导入指南

本包用于在 **AionUi 应用**中添加「邮局委办报表助手」。导入后，助手会按 Claude Code 处理邮局报表的工作方式运行。

## 导入步骤

### 步骤 1：准备资源目录

把整个 `aionui-assistant-package/resources/` 文件夹放到一个**固定位置**，建议：

- Windows: `D:\项目\邮局\aionui-assistant-package\resources`
- macOS/Linux: `~/post-office-assistant/resources`

记下这个绝对路径，后面要用。

### 步骤 2：安装 Python 依赖

```bash
pip install openpyxl
```

验证：
```bash
python3 <资源目录>/scripts/check_env.py
```

Windows 下 `python3` 不存在用 `python`。

### 步骤 3：导入三个技能

打开 AionUi 应用 → 设置 → 技能（Skills）→ 导入：

1. 选 `skills/post-office-build-draft` 文件夹 → 导入
2. 选 `skills/post-office-build-split` 文件夹 → 导入
3. 选 `skills/post-office-build-pnl` 文件夹 → 导入

三个技能都应出现在技能列表。

### 步骤 4：导入助手

设置 → 助手（Assistants）→ 导入助手 → 选 `assistants-import.json`。

「邮局委办报表助手」出现在助手列表。

### 步骤 5：粘贴系统提示词

进入「邮局委办报表助手」的编辑页 → 找到「规则」或「系统提示词」编辑框 → 打开 `assistant-rule.md`，**全文复制粘贴**进去 → 保存。

> ⚠ `assistant-rule.md` 里有一处 `<RESOURCES_DIR>` 占位符，把它替换成步骤 1 的实际绝对路径。
> 例：`<RESOURCES_DIR>` → `D:\项目\邮局\aionui-assistant-package\resources`

### 步骤 6：确认三个技能已绑定

助手编辑页里，确认「已启用技能」包含：
- post-office-build-draft
- post-office-build-split
- post-office-build-pnl

如果没有，手动勾选启用。

### 步骤 7：测试对话

新建对话，选「邮局委办报表助手」，试：

```
帮我生成4月基础报表初版
```

助手应该依次问你要 6 个文件（一次一个），收齐后调脚本生成初版，汇报指标后停下。

如本机保留了 4 月测试数据，再运行：

```bash
python3 <资源目录>/scripts/test_runner.py
```

看到初版、拆分、盈亏全部通过后再投入正式使用。

## 常见问题

**Q: 助手说找不到脚本路径？**
A: 检查 `assistant-rule.md` 里的 `<RESOURCES_DIR>` 是否替换成了实际绝对路径。

**Q: 脚本运行报错 ModuleNotFoundError: openpyxl？**
A: `pip install openpyxl`。如果多个 Python 版本，用 `python3 -m pip install openpyxl`。

**Q: 助手不调脚本，自己瞎处理？**
A: 系统提示词里强调了"脚本当工具用"，但 LLM 偶尔会自由发挥。出现这种情况提醒它："请调 build_draft.py 脚本"。

**Q: 想修改助手行为？**
A: 编辑 `assistant-rule.md` 后重新粘贴到规则编辑器。或直接在对话里说"记住以后遇到 X 情况就 Y"。

**Q: 用什么模型？**
A: 建议使用支持长上下文、工具调用和代码执行的中高端模型。弱模型可以做文件收集，但不适合独立判断模板变化和路线歧义；无论用什么模型都要跑验证并保留人工闸门。

## 卸载

1. AionUi 设置 → 助手 → 删除「邮局委办报表助手」
2. AionUi 设置 → 技能 → 删除三个 post-office-* 技能
3. 删除资源目录
