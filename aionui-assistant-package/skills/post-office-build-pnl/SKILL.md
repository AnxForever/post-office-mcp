# 盈亏表

## ⛔ 闸门
**必须先问**："初版核对过了吗？请提供核对修正后的初版。" 没核对不执行。

## 输入
核对后初版 + 财务收入表 + 盈亏模板目录(含一干委办盈亏.xlsx + 二干委办盈亏.xlsx) + 月份

## 关键算法

### 读取模板
```python
# 盈亏模板有多个月份Sheet，选最后一个有效月份
# 有效Sheet: Row2 Col1="邮路名称" 且 Sheet名含"月"
# 从该Sheet动态读取: 车型组(7列/组)、路线顺序(col1)、环比区结构

# 车型组解析: 每个车型组正好7列
#   趟次 | 装载量 | 每车平均装载量 | 运费 | 结算收入 | 盈亏值 | 平均每车盈亏
# 末尾4汇总列: 总趟次 | 总运费 | 总结算 | 总盈亏
```

### 聚合数据
```python
# 装载量 + 运费 → 从初版聚合: sum(运输量) sum(运价) group by 路线+吨位
# 趟次 + 结算收入 → 从财务表聚合: count(路线+吨位) sum(结算收入−普服收入)
#   财务表列按表头动态定位: 邮路级别/邮路名称/额定吨位/结算收入/普服收入
#   一干: 仅以"西安"开头的正向路线; 二干: 路线去西安-前缀
# 盈亏 = 结算收入 − 运费
```

### 输出格式
```python
# 路线顺序照搬模板col1, 模板无的路线不进盈亏表
# 模板有但本月无数据的保留空行
# 上海东/西→合并为"西安-上海"
# 底部环比区: 上月(读上一月份模板Sheet合计) / 本月(=本表合计) / 环比=((本月-上月)/上月)%
# 数字格式: 趟次0位小数, 运费/盈亏万元格式 0"."0,"万元"
# 抽样验证: 抽3条路线, 趟次/结算/运费全部吻合才交付
```

## ⚠ traps
- **模板选最后一个有效月份Sheet**，不是第一个旧月份
- 车型组7列/组，**从模板动态读**，不写死
- 路线顺序照搬模板col1
- 结算收入 = Col结算 − Col普服（列按表头名定位, 不写死列号）
- 一干过滤反向路线(不以"西安-"开头)
- 额定吨位=0或空 → 跳过

## 输出
- `N月_04_一干盈亏表.xlsx`
- `N月_04_二干盈亏表.xlsx`
