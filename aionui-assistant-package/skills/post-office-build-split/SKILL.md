# 基础报表拆分版

## ⛔ 闸门
**必须先问**："初版核对过了吗？请提供核对修正后的初版。" 没核对不执行。

## 输入
核对后初版 + 拆分模板(`基础报表原版.xlsx`) + 月份

## 关键算法 — code.execute 实现

```python
# 1. 读初版「基础报表」Sheet，按表头名定位列(不写死列序)
#    需要: 车辆承运单位/派车单号/邮路名称/封车时间/车牌号/容间/吨位/公里/运输量/运价/标准价/备注

# 2. 读模板所有Sheet
#    跳过: 降吨位/二干基础/两趟合一趟/一干汇总/Sheet1-4
#    每个Sheet: 复制表头(第1行) + 列数(17或18列) + 列宽 + 样式
#    从模板已有数据学习 路线→Sheet归类规则

# 3. 按目的地城市归类记录 → 对应Sheet
#    同城可能有"xx二干"和"xx"两个Sheet——都保留
#    模板无的路线→新建Sheet加※前缀,追尾 模板有但无数据→保留空表头

# 4. 容间取整数: int(round(vol))

# 5. 每个Sheet末行 SUM公式(运输量+运价列)

# 6. 验证: 拆分版所有序号行合计 = 初版数据行数
```

## ⚠ traps
- Sheet名/顺序/列数/表头全照搬模板, 不自己排
- 17列和18列两种格式, 逐Sheet复制, 不能套初版的21列
- 容间取整数
- 空Sheet保留占位(不删)
- 新建Sheet加※前缀追尾

## 输出
`N月_03_基础报表拆分版.xlsx`，~100 Sheet，和模板格式一致。
