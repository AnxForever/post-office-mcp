# 车型汇总表 = 草滩在线表 + 港务在线表 当月全部记录合并

**不是统计！不是分类！就是把两张表的当月所有行拼成一张表。**

## 步骤（每一步单独 code.execute，不做多件事）

### 第1步：统计有多少 Sheet
```python
import openpyxl
for f in ['草滩在线表.xlsx','港务在线表.xlsx']:
    wb = openpyxl.load_workbook(f, data_only=True)
    sheets = [s for s in wb.sheetnames if s.startswith(('4月','4.'))]
    print(f, len(sheets), sheets[:3])
    wb.close()
```

### 第2步：读草滩所有4月Sheet的行
- Sheet名匹配 `4月` 开头的（正则 `^\d+月\d+日?$`）
- 表头在第3行（openpyxl 1-indexed），数据从第4行开始
- 列：序号(C1) | 邮路(C2) | 车号(C3) | 挂车号(C4) | 长(C5) | 宽(C6) | 高(C7) | 测量容积(C8) | 预报载重(C9) | 未装容积(C10) | 车型问题(C11)
- **测量容积(C8)是Excel公式 =长×宽×高，读取为None时用 C5×C6×C7 计算**

### 第3步：读港务所有4月Sheet的行
- Sheet名匹配 `4.` 开头的（正则 `^\d+\.\d+$`）  
- 表头在第3行，数据从第4行
- 列：序号(C1) | 邮路名称(C2) | 车牌号(C3) | 车厢车牌号(C4) | 长(C5) | 宽(C6) | 高(C7) | 测量容积(C8) | 预报载重(C9) | 未装容积(C10) | 车型问题(C11)

### 第4步：合并 + 跨场地补容间
- 两张表的行纵向拼接
- 统一列名：车号/车牌号→车牌 | 挂车号/车厢车牌号→挂车 | 邮路/邮路名称→邮路
- 加一列"场地"：草滩表行填"草滩"，港务表行填"港务"
- 跨场地补容间：草滩行容积为空时 → 找同车牌在港务行中任意容积>0的，补上
- **不去重**

### 第5步：写 Excel
- 列：序号（重新编号1开始）| 测量日期 | 场地 | 邮路 | 车牌 | 挂车 | 长 | 宽 | 高 | 容积 | 车型问题
- 保存为 `N月_01_车型汇总表.xlsx`

## 预期结果
草滩约900行 + 港务约2300行 = **~3200行**。如果是别的数字，说明漏读了Sheet。
